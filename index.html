DeckíReader

Track the books you are reading.

Setup

DeckíReader keeps no reading data on the server. Paste CSV, choose a local file, or load a public CSV URL.

Use a header row. Tap to learn more about the CSV format. Required columns: id,title,author

Header row

This is the complete header. Columns can be reordered or left out unless they are required, column names are case-sensitive, and an unknown column is rejected so a typo never silently drops data. 

id,title,titleEn,author,pages,difficulty,genre,startedAt,finishedAt,notes,isbn10,isbn13

Fields

id Required
Unique, stable identifier. A short lowercase slug works well, and duplicate values are rejected.
title Required
The book title as you want it displayed.
author Required
Author display name.
titleEn
Optional English or alternate title, shown beneath the title.
pages
Optional whole number of 1 or more.
difficulty
Optional personal rating from 1 (easier) to 5 (more challenging).
genre
Optional genre. A blank value becomes other, and custom values are kept as typed. Recognized values: literary, mystery, sf, fantasy, romance, slice-of-life, folk-tales, essay, nonfiction, biography, history, science, business, self-help, psychology, design, manga, other
startedAt
Optional start date in YYYY-MM-DD format.
finishedAt
Optional finish date in YYYY-MM-DD format.
notes
Optional freeform notes. Notes are searchable but are not shown in the table.
isbn10
Optional ISBN-10, stored as text.
isbn13
Optional ISBN-13, stored as text.

Status and dates

  • A row with a finishedAt date is finished.
  • A row with only a startedAt date is reading.
  • A row with neither date is planned, and it appears only under All-time.
  • A finish date alone is fine when the start is unknown, but finishedAt cannot come before startedAt.

Quoting

  • Separate fields with commas.
  • Wrap a field in double quotes when it contains a comma, a quote, or a line break.
  • Escape a double quote inside a quoted field by doubling it.
  • Blank optional fields are allowed, but a row may not hold more fields than the header.
  • A UTF-8 byte-order mark is accepted.

Example

id,title,titleEn,author,pages,difficulty,genre,startedAt,finishedAt,notes,isbn10,isbn13
example-book,"A Title, With a Comma",,Example Author,240,3,nonfiction,2026-01-05,2026-02-12,"Good pacing; contains the line ""keep going.""",,
